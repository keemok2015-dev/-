# انتشار الموقع + الإعلانات + الأرباح الحقيقية

تمت إضافة طبقة تقنية تساعد كورة لايف على الظهور في محركات البحث وتحسين المشاركة، مع تجهيز Google AdSense دون اختلاق أي بيانات.

## 1) قبل النشر
ضع القيم الحقيقية في متغيرات البيئة:
- `VITE_SITE_URL`: النطاق الحقيقي للموقع.
- `VITE_ADSENSE_CLIENT`: رقم الناشر الذي يعطيك إياه AdSense بعد الموافقة.
- `EARNINGS_API_URL` و`EARNINGS_API_TOKEN`: مصدر أرباح حقيقي على الخادم.
- `ADMIN_PASSWORD`: كلمة مرور المالك.

ثم استبدل `YOUR-DOMAIN.example` في `public/robots.txt` و`public/sitemap.xml` بالنطاق الحقيقي.

## 2) الإعلانات
لا يمكن جلب إعلانات Google الحقيقية أو أرباحها قبل امتلاك حساب ناشر وموافقة مزود الإعلانات. بعد الموافقة، ضع Client ID وأضف AdSlot بالمكان المطلوب:

```tsx
<AdSlot slot="YOUR_REAL_AD_SLOT_ID" />
```

لا تستخدم Publisher ID أو Ad Slot مخترعًا.

## 3) الانتشار
تم تجهيز:
- robots.txt
- sitemap.xml
- canonical URL
- Open Graph / Twitter metadata
- WebSite structured data
- وصف عربي مناسب للبحث
- أساس لتحسين مشاركة صفحات الموقع

هذا يحسن قابلية الاكتشاف، لكنه لا يضمن ترتيبًا معينًا أو انتشارًا فيروسيًا. النشر الآلي المزعج أو شراء زيارات/نقرات إعلانية غير حقيقية ليس جزءًا من النظام.

## 4) الأرباح
لوحة المالك لا تعرض أرباحًا وهمية. يجب أن يعيد مزود الأرباح JSON بصيغة:

```json
{
  "total": 123.45,
  "available": 100.00,
  "currency": "SAR",
  "monthly": [{"label":"2026-10","value":123.45}]
}
```

الأفضل استخدام Backend/Serverless لإخفاء مفاتيح مزود الأرباح وعدم وضعها في `VITE_*`.
